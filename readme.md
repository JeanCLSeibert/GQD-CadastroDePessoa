## Evolução da qualidade de projeto, Disciplina Gestão da Qualidade de Software
Para executar:
* python -m venv .venv - Cria seu ambiente virtual
* source .venv/bin/activate - Ativa o mesmo
* pip install -r requirements.txt  - Instala as dependências
* source .env - Adiciona os ENVs, vai pedir a senha do banco!
* python src/main.py
